# **Hitos propuestos**

3. `M2`: jugador puede preparar una sala en demo. Fase 2.
4. `M3`: tablero local reproduce una partida de ejemplo. Fase 3.

7. `M6`: guía de integración, calidad y entrega. Fase 6.
