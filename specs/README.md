# **Especificaciones de Bomberman Online**

Estado: propuestas iniciales del 14 de octubre de 2026. Ninguna función de las fases 1 a 6 está aprobada ni implementada. La Fase 0 incluye solo el shell y los documentos.

Cada función sigue `spec.md`, `design.md`, `tasks.md` y `acceptance.md`. Revisamos requisitos, contrato y dudas antes de empezar código. Si un contrato cambia, actualizamos su especificación y las pruebas asociadas.

Las decisiones abiertas están en [architecture/decisions/0001-initial-boundaries.md](architecture/decisions/0001-initial-boundaries.md). OpenAPI y SignalR son propuestas para acordar con quienes construyen el backend.
