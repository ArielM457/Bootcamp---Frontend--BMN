# **ROOM-01 · Salas**

Estado: integración HTTP implementada el 9 de noviembre de 2026. Como jugador quiero listar, crear y unirme a una sala para esperar una partida.

Requisitos: listado y detalle, participantes, pista elegida, límite de 2 a 8 plazas, anfitrión e inicio autorizado. Tanto Partida local como Crear sala crean primero una sala de espera y unen al creador. El anfitrión puede volver al mismo formulario para cambiar tipo, nombre, capacidad y pista antes de iniciar. Las pistas iniciales son abierta, con pocos obstáculos, y fortaleza, con muchos obstáculos. Cada jugador puede estar en una sola sala de espera. El anfitrión puede añadir varios bots locales hasta completar las plazas disponibles. Cada bot ocupa una plaza, cuenta para el mínimo de 2 participantes y no ejecuta acciones. El anfitrión puede iniciar con al menos 2 participantes. Con una sola persona, el botón debe mostrar Esperando jugadores y permanecer deshabilitado. Al salir el anfitrión, el siguiente jugador humano ocupa su lugar. Si solo quedan bots, la sala se elimina.

En la integración HTTP, el backend asigna un código alfanumérico único de 8 caracteres al crear la sala. La sala de espera muestra el código para compartirlo. Otro jugador puede unirse mediante ese código. Cuando la partida comienza, el detalle de la sala cambia a `playing` e incluye `gameId`; los participantes que esperan consultan el detalle y entran a la misma partida. Errores: sala llena, iniciada, inexistente, código inválido, sesión vencida y desconexión. Depende de AUTH-01 y LOBBY-01.
