# **Aceptación SCORE-01**

- Al terminar una partida se muestran resultado, puntos, vidas y tiempo restante.
- El ranking muestra nombre, puntos, victorias y posición en orden definido.
- Una lista vacía presenta una explicación clara.
- Un fallo de carga permite reintentar sin inventar puntuaciones.
- El mismo resultado recibido varias veces se registra una sola vez.
