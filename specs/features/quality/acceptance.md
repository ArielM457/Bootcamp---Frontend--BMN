# **Aceptación QA-01**

- El primer enlace de teclado permite saltar directamente al contenido.
- Enlaces, botones y campos muestran foco visible.
- La aplicación reduce animaciones cuando el sistema lo solicita.
- El ranking mantiene posición, jugador, puntos y victorias en pantalla pequeña.
- El flujo local permite crear una sala, añadir un bot, iniciar, jugar y registrar un resultado.
- La documentación distingue funciones locales, integraciones pendientes y comprobaciones manuales.
- La configuración elige los adaptadores según el modo; el modo api falla al iniciar con un mensaje que nombra los adaptadores pendientes.
