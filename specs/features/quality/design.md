# **Diseño QA-01**

El shell añade un enlace de salto visible al recibir foco y un destino común para el contenido de cada ruta. Los estilos globales mantienen foco visible y respetan la preferencia de movimiento reducido. Las pantallas conservan su diseño retro y adaptan la información sin ocultar datos principales.

Una prueba de flujo usa los mismos adaptadores locales que la aplicación para recorrer sala, bot, inicio, movimiento, resultado y ranking. La guía de integración explica qué adaptadores debe reemplazar el backend sin cambiar componentes ni facades.
