# **Aceptación AUTH-01**

- Con datos válidos se crea una cuenta y se muestra el perfil confirmado.
- Un login válido abre el dashboard; uno inválido muestra error sin crear sesión.
- Una ruta protegida redirige cuando no hay sesión.
- Cerrar sesión impide volver a una ruta protegida sin entrar de nuevo.
- Una respuesta 401 elimina o renueva la sesión según el contrato aprobado.
