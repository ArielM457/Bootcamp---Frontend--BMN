# **Aceptación REAL-01**

- Al unirse se muestran participantes confirmados.
- Los comandos rechazados muestran una respuesta clara y no cambian el estado definitivo.
- Un evento con versión vieja no revierte el tablero.
- Al reconectar se pide y aplica un snapshot vigente antes de habilitar entradas.
- Si la reconexión falla, la UI informa y permite salir con seguridad.
