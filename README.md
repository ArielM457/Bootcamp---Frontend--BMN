# **Bomberman Online Frontend**

Base Angular del bootcamp CodeSprint. Esta primera entrega incluye una bienvenida, navegación, estructura y propuestas de contratos. Aún no hay autenticación, salas ni juego funcional.

## **Requisitos**

- Node.js 24.12 o una versión compatible con Angular 21.
- npm 11.

## **Comandos**

```bash
npm ci
npm start
npm run build
npm test -- --watch=false
npm run lint
npm run format:check
```

## **Documentación**

Lee [specs/README.md](specs/README.md) antes de desarrollar. Los contratos son propuestas pendientes de validar con el backend. Las skills de `.agents/skills/` son locales y no se versionan.
